# RAMTech RVSC Control Center

Central governance and orchestration repository for the RAMTech Virtual Software Company (RVSC).

This repository contains control-plane definitions, work-package governance, repository registry data, agent boundaries, validation rules, and operational documentation. Product source code must live in its own managed repository and must not be stored here.

Current checkpoint: **RVSC-013 — Git / Source Isolation**.
