## Registration rules
- A project is not considered RVSC-managed until its repository boundary is registered here and governed by the active Work Package contract.
- Source repositories remain isolated from the Control Center.
- `main` is an integration baseline; routine development occurs only on declared work branches.
- Readiness credit comes from accepted evidence, not conversation estimates.

## Next registration gate
Additional RAMTech products will be registered only after their source-of-truth repository and protected baseline are identified. This prevents accidental cross-project source mixing.
